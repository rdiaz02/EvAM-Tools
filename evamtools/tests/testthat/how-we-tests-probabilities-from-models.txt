* MHN:
- Most direct test: in test.probs-from-trm.R : compares against Schill's code (Generate.pTh). *This tests the function probs_from_trm*.
  - This tests the probabilities themselves, and therefore also indirectly that the transition rate matrices are constructed correctly.

- Direct for transition rate matrices: test.trans-rates-MHN.R . This  tests construction of transition rate matrices. trm0 is a fully hand-computed reference matrix (every entry built from exp(theta) products), and all algorithm variants are compared against it with expect_identical. There's even a specific numerical spot-check (eme1[3,3] * eme1[3,4] == trm0["D", "C, D"]), plus comparison against Schill's Build.Q.

- Indirect: under evamtools/inst/miscell/tests-sample_genotypes_from_trm: this is a probabilistic comprobation and it does not test probs_from_trm but random samples from the transition rate matrix. So this is another test that the transition rate matrix is constructed correctly. It is not run routinely, though.

- Indirect, not in use: you can run this, but this does not run in the standard checks: in test.probs-from-trm.R we compare, for MHN, CBN, and H-ESBCN, that probs_from_trm and sampling from the transition rate matrix give the same results. I've run it in the past, and things were fine (but terribly slow and this is not an automated test).

* CBN and HESBCN
- *probs_from_trm* is tested directly above. It is embedded in a test that also depends on constructing the trm correctly for MHN. But for this tests to work when probs_from_trm fails would require cancelling errors. The probability of this happening is essentially null.

- Indirect, not in use: you can run this, but this does not run in the standard checks: in test.probs-from-trm.R we compare, for MHN, CBN, and H-ESBCN, that probs_from_trm and sampling from the transition rate matrix give the same results.
